# Sources

Every file in `reports/` is generated by a script in `src/`. Nothing is hand-edited.
Rebuild the inputs with `python -m src.get_data`, then the outputs with the script named below.

## Data

**Murder Accountability Project**, UCR homicide and clearance data (UCR65_25), murderdata.org, accessed 2026-10-28.
FBI Uniform Crime Report murder and clearance counts per agency, 1965 to 2025. Dallas Police Department = ORI `TXDPD00`.

**The Washington Post**, Unsolved Homicide Database, github.com/washingtonpost/data-homicides, 2018.
Case-level homicides, Dallas subset (1,567 cases, 2007 to early 2017). Licensed CC BY-NC-SA 4.0.

## Outputs

| File | Built by | Source | "Cleared" means |
|---|---|---|---|
| `dallas_series.csv` | `src/series.py` | MAP / FBI UCR | FBI definition: cleared by arrest **or** exceptional means, counted in the year the clearance happened (can include prior-year cases) |

The Washington Post counts a case solved only when its disposition is `Closed by arrest`.
That is a different definition from the FBI's. Any comparison of the two must say so.

Aggregate analysis only: victim names are dropped on load and never appear in any output.
